# Game artwork

Artwork from the game [*Legends of Idleon*](https://www.legendsofidleon.com) by LavaFlame2.

`manifest.json` lists every file with its byte count and sha256; the app resolves every image
through it. Add a manifest entry with each new image.

## Section icons

`sections/<section>.png` is each section's sidebar and dashboard icon (the registry's `art`),
copied unchanged from the web client's named sprite listed here; the emoji stays as the fallback
when a file is missing. How to take more: `docs/game-data-sources.md`, "Taking game art".
